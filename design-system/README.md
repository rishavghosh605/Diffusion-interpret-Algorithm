# Design system reference

This folder is a pointer, not a copy of the full system. The actual design system (tokens, components, brand book) lives as a Claude Artifact and stays the single source of truth:

https://claude.ai/artifact/V3jCEgg4q19sUnDAPRVvyg

## Why this is here

Any artifact, diagram, or visual explainer built out of this repo (e.g. a diffusion process visualization, an interactive notebook page) should default to this design language rather than inventing a new one each time.

## The essence, in short

Warm, present, rooted. Calm surfaces, meaning before decoration, no elements that feed anxiety or comparison (no scores, streaks, red alarms). Text passes the "exhale test": if a line makes someone tense, it's wrong.

- Text in `ink` on `paper`/`card`/`zone`; secondary text `muted`. 4.5:1 contrast minimum, both themes (day/night).
- `flame` is the one live accent — marks focus, now, and active choice. Never used as a large fill.
- Type: serif (Literata) for authored words/quotes, sans (Figtree) for tool/UI words.
- Soft radii, hairline borders on resting elements, `shadow-lift` only on floating elements.
- No AI-generic tropes: no blue-purple gradients, no emoji cards, no left-border cards.

Full brand book, tokens, and components: read directly from the artifact above before building anything visual.
